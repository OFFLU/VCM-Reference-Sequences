Purpose: This document proposes a set of publicly available reference haemagglutinin (HA) sequences for priority zoonotic avian influenza A virus subtypes and lineages, for optional use in zoonotic data packages submitted to the biannual WHO Vaccine Composition Meetings (VCMs). These meetings inform candidate vaccine virus (CVV) recommendations for pandemic preparedness. The reference sequences are intended to provide consistent genetic anchors for phylogenetic analyses, supporting greater standardisation, interpretability and comparability across data packages. The reference sequence set is expected to be reviewed and updated approximately every two years.
