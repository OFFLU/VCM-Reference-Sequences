Purpose: Here we propose a set of available reference haemagglutinin (HA) sequences for priority zoonotic avian influenza A virus subtypes and lineages, for optional use in zoonotic data packages submitted to the biannual WHO Vaccine Composition Meetings (VCMs). These meetings inform candidate vaccine virus (CVV) recommendations for pandemic preparedness. The reference sequences are intended to provide consistent genetic anchors for phylogenetic analyses, supporting greater standardisation, interpretability and comparability across data packages. The reference sequence set is expected to be reviewed and updated approximately every two years.

Methods: Influenza A virus (IAV) subtype-specific haemagglutinin (HA) sequences from 1 January 2020 to 13 April 2026 were downloaded from GISAID EpiFlu [1]. H5 and H9 clades or lineages were defined using the latest nomenclature updates [2,3]. Data were restricted to sequences with at least 70% coverage of the full-length HA segment, with clades/lineage-specific host filters applied as needed, including exclusion of human seasonal H3N2 viruses. Lineage- or clade-specific sequence specific sequences were aligned using MAFFT v7.520 [4] and cleaned in R v2025.05.1 [1,5] to remove duplicates, sequences with excessive gaps or ambiguous bases, guano-derived sequences, and embargoed sequences. Highly divergent sequences consistent with sequencing error were removed following additional inspection, including in TempEST v1.5.3 [6].  Maximum likelihood phylogenies were inferred using RAxML-NG v2.0.1 [7]. Trees were reduced to scaffold trees using the decomposition step in Splicer [8] (https://github.com/flu-crew/splicer), and PARNAS [9] (https://github.com/flu-crew/parnas) was used to select representative sequences that best captured the observed phylogenetic diversity by minimising the evolutionary distance between each sequence and its nearest selected representative. A target of 10–15 sequences was used for each dataset, depending on dataset size, alongside a target of ≥80% total diversity coverage. In practice, this means that the selected representatives together captured at least 80% of the observed phylogenetic diversity, measured as the reduction in weighted evolutionary distance between all sequences and their nearest selected representative. Manual additions or adjustments were made where needed to ensure appropriate representation.
